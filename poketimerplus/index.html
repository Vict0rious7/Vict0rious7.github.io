PokeTimerPlus

All-in-one RNG timer for Pokémon on real hardware.

PokeTimerPlus brings together EonTimer's timers and calibration and FlowTimer's flowing targets, with beeps that land when they should. It has the same look as PokeFinderPlus. Work in progress: report bugs in the issues.

DownloadSource on GitHub

Beeps on time

  • Beeps are written into an audio stream that stays open, at exact sample positions. Measured on a MacBook Air: every beep within 0.2 ms, including on battery, with a video playing and on a Bluetooth speaker.
  • Drift between the sound card's clock and the system clock is detected and corrected between countdowns.
  • No network access at all, so nothing fails when you're offline.

Organised by console

  • Tabs for GB/GBA, DS, 3DS and Switch, each listing its RNG types, with a Custom timer on every tab.
  • Ruby/Sapphire/Emerald wild, static, fishing and eggs; FireRed/LeafGreen static, wild and eggs; Diamond/Pearl/Platinum and HeartGold/SoulSilver; X/Y Trainer ID.
  • FireRed/LeafGreen timer with seed time and target advance, each with its own calibration, matching PokeFinderPlus' initial seed results.
  • "Played on": GBA, GBA game on DS, open_agb_firm, Game Boy Interface, Switch, DS, 3DS, or any frame rate.

Calibration that sticks

  • Save each RNG type's calibration to your profile, so it's filled in next time.
  • "Hit" fields on every timer: type what you got, and the calibration is corrected.
  • Flowing targets: start the clock, then type each target when you know it.

Download

Get the latest version on the Releases page, under Assets.

  • Windows 10 / 11: PokeTimerPlus-windows.zip. Unzip and run PokeTimerPlus.exe. If Windows shows "Windows protected your PC", click More info → Run anyway.
  • macOS (Intel or Apple Silicon): PokeTimerPlus-macos.zip. Move the app to Applications, then right-click → Open the first time.
